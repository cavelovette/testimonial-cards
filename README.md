# Testimonial Cards

A set of testimonial cards built with HTML and CSS to practice positioning and
layout (flexbox, absolute positioning with pseudo-elements, responsive design).

## Project URL
https://roadmap.sh/projects/testimonial-cards

## Features
- Speech-bubble card with a CSS triangle tail (`position: absolute`)
- Outlined card with author avatar
- Featured card with photo, star rating and dark panel
- Carousel-style card with avatar thumbnails and arrow buttons
- Responsive layout (cards stack on small screens)
